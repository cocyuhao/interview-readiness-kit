## Interview Talk Track

I usually present the portfolio as three threads:

1. Product delivery: the OpenClaw Forge project demonstrates a product-like AI AgentOps interface, not just a script.
2. AI/ML foundation: the BrainNet projects show data preprocessing, modeling, evaluation, and explainability.
3. Engineering discipline: the automation proof repositories show validation, recording, reproducibility, and handoff thinking.

## What To Ask Me About

- How the AgentOps demo models task state, skill publishing, and proof artifacts.
- How the BrainNet system separates model research code from the web demo platform.
- Why browser-level verification matters for AI-generated or AI-assisted products.
- How I use reusable skills, local tooling, and GitHub handoff materials to make work reviewable.
